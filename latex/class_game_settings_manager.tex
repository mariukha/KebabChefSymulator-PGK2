\doxysubsection{Opis szczegółowy}
Menedżer ustawień gry implementujący wzorzec Singleton. Zarządza wszystkimi konfigurowalnymi ustawieniami gry\+: grafiką, dźwiękiem i sterowaniem. Ustawienia są automatycznie ładowane z Player\+Prefs przy inicjalizacji i zapisywane po każdej zmianie. 

Klasa zapewnia zestaw predefiniowanych rozdzielczości i limitów FPS. Obsługuje przełączanie między trybem pełnoekranowym a okienkowym, cykliczne przełączanie ustawień oraz bezpośrednie ustawianie wartości suwakowych.
