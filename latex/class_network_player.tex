\doxysubsection{Opis szczegółowy}
Główna klasa gracza sieciowego odpowiedzialna za zarządzanie lokalnym i zdalnym graczem. 

Dziedziczy po Network\+Behaviour i obsługuje\+: 
\begin{DoxyItemize}
\item Konfigurację kamery i kontrolera gracza lokalnego 
\item Tworzenie wizualnej reprezentacji graczy zdalnych 
\item Synchronizację trzymanego przedmiotu, nazwy gracza i indeksu 
\item Nadawanie stanów stacji kuchennych, ekonomii, sklepu i zamówień 
\item Obsługę interakcji ze stacjami kuchennymi przez RPC 
\item Nadawanie efektów wizualnych (VFX) do klientów 
\end{DoxyItemize}
