\doxysubsection{Opis szczegółowy}
Klasa singleton odpowiedzialna za konfigurację sieci w grze wieloosobowej. 

Zarządza cyklem życia Network\+Manager\+: 
\begin{DoxyItemize}
\item Tworzenie i konfiguracja Network\+Manager oraz Unity\+Transport 
\item Dynamiczne tworzenie prefabu gracza z wymaganymi komponentami 
\item Uruchamianie trybu hosta lub klienta 
\item Obsługa zdarzeń połączenia i rozłączenia graczy 
\item Spawnowanie obiektów graczy na serwerze 
\end{DoxyItemize}Używa wzorca singleton z \doxylink{class_network_setup_a781962d28fc313f110a7c80a26978b92}{Instance}.
