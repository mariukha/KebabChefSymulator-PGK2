\doxysubsection{Opis szczegółowy}
Wewnętrzna klasa obsługująca instancjonowanie i niszczenie prefabów graczy sieciowych. 

Implementuje INetwork\+Prefab\+Instance\+Handler do dynamicznego tworzenia obiektów graczy z odpowiednim hashem identyfikacyjnym. Używana przez system prefabów Netcode zamiast standardowego mechanizmu prefabów.
