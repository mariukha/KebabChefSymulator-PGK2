Aktualizuje animację zanikania w każdej klatce. Zmniejsza przezroczystość nakładki proporcjonalnie do upływającego czasu. Po zakończeniu zanikania dezaktywuje obiekt nakładki. 

Używa Time.\+unscaled\+Delta\+Time zamiast Time.\+delta\+Time, aby animacja działała poprawnie nawet gdy gra jest wstrzymana (Time.\+time\+Scale = 0).
