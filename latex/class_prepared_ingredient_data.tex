\doxysubsection{Opis szczegółowy}
Klasa reprezentująca dane przygotowanego składnika. Przechowuje informację o rodzaju składnika oraz jego aktualnym stanie przetworzenia. Używana jako element listy zawartości gotowej potrawy (\doxylink{class_kitchen_item_a17f90ea6bae8d28c174304498d81bf93}{Kitchen\+Item.\+contents}). 

Klasa jest serializowalna, co umożliwia jej zapis i przesyłanie przez sieć. W przeciwieństwie do \doxylink{class_ingredient_requirement}{Ingredient\+Requirement}, ta klasa nie przechowuje ilości — każda instancja reprezentuje dokładnie jeden egzemplarz składnika.
