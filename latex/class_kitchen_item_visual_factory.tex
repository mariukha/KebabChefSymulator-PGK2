\doxysubsection{Opis szczegółowy}
Statyczna klasa fabryki tworząca wizualne reprezentacje 3D składników i dań kuchennych w grze Kebab Chef Symulator. 

Klasa pełni rolę centralnej fabryki do tworzenia obiektów wizualnych dla systemu kuchni. Obsługuje\+:
\begin{DoxyItemize}
\item Ładowanie modeli 3D z katalogu Resources/\+Models/ z buforowaniem,
\item Tworzenie prymitywów zastępczych (kula, cylinder) gdy model nie jest dostępny,
\item Generowanie rozproszonych wizualizacji składników (posiekane warzywa, sos),
\item Buforowanie materiałów i shaderów dla optymalizacji wydajności,
\item Automatyczne skalowanie modeli do pożądanego rozmiaru,
\item Integrację z systemem animacji pojawiania się (\doxylink{class_item_animator}{Item\+Animator}). 
\end{DoxyItemize}
