\doxysubsection{Opis szczegółowy}
Główna klasa zarządzająca systemem sklepu z ulepszeniami. 

Implementuje wzorzec Singleton. Odpowiada za\+:
\begin{DoxyItemize}
\item Rejestrację i przechowywanie definicji dostępnych ulepszeń
\item Śledzenie aktualnych poziomów każdego ulepszenia
\item Obsługę zakupu ulepszeń z weryfikacją salda gracza
\item Dostarczanie wartości efektów ulepszeń innym systemom gry (grillowanie, krojenie, nagrody, czas zamówień, wielkość porcji)
\item Serializację i deserializację stanu sklepu dla systemu zapisu gry
\end{DoxyItemize}

Współpracuje z \doxylink{class_economy_manager}{Economy\+Manager} (system finansów) oraz \doxylink{class_save_manager}{Save\+Manager} (system zapisu).
