Opis szczegółowy

Klasa definiująca pojedyncze ulepszenie dostępne w sklepie.

Przechowuje wszystkie informacje potrzebne do wyświetlenia ulepszenia w interfejsie użytkownika, obliczenia kosztu na danym poziomie oraz opisu efektu ulepszenia. Klasa jest serializowalna, co umożliwia konfigurację z poziomu inspektora Unity.

Dokumentacja funkcji składowych

◆ GetCostForLevel()

float UpgradeDefinition.GetCostForLevel ( int nextLevel)
inline

Oblicza koszt ulepszenia dla podanego następnego poziomu.

Parametry
nextLevelNumer poziomu, na który gracz chce ulepszyć (0 oznacza pierwszy zakup).
Zwraca
Zaokrąglona kwota kosztu ulepszenia. Dla poziomu 0 lub mniejszego zwraca baseCost.

Koszt jest obliczany wykładniczo: baseCost * costScaling^nextLevel, a wynik jest zaokrąglany do najbliższej liczby całkowitej dla czytelności w interfejsie.

◆ GetEffectDescription()

string UpgradeDefinition.GetEffectDescription ( int currentLevel)
inline

Generuje tekstowy opis efektu ulepszenia na następnym poziomie.

Parametry
currentLevelAktualny poziom ulepszenia.
Zwraca
Czytelny opis efektu ulepszenia (np. "-20% czasu", "+10% nagrody", "4 porcji") lub "MAX" jeśli ulepszenie osiągnęło maksymalny poziom. Zwraca pusty ciąg jeśli brak zdefiniowanych wartości efektów.

Format opisu zależy od typu ulepszenia:

  • GrillSpeed / CuttingSpeed: procent redukcji czasu
  • RewardBonus: procent bonusu do nagrody
  • OrderTime: dodatkowe sekundy
  • MeatBatchSize: liczba porcji

float UpgradeDefinition.costScaling

Współczynnik skalowania kosztu dla kolejnych poziomów.

Koszt kolejnego poziomu obliczany jest jako: bazowy koszt * (współczynnik ^ poziom). Wyższa wartość oznacza szybszy wzrost ceny ulepszeń.
