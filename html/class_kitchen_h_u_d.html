Dokumentacja klasy KitchenHUD

Klasa zarządzająca interfejsem HUD w scenie kuchni. Odpowiada za tworzenie i aktualizowanie wszystkich elementów UI widocznych podczas rozgrywki, w tym: paska salda, informacji o trzymanym przedmiocie, licznika zamówień, celownika, powiadomień oraz timera pilności zamówienia. Więcej...

Opis szczegółowy

Klasa zarządzająca interfejsem HUD w scenie kuchni. Odpowiada za tworzenie i aktualizowanie wszystkich elementów UI widocznych podczas rozgrywki, w tym: paska salda, informacji o trzymanym przedmiocie, licznika zamówień, celownika, powiadomień oraz timera pilności zamówienia.

Cały interfejs jest tworzony programowo w metodzie CreateCanvas wywoływanej w Awake. Klasa wyszukuje gracza sieciowego w scenie, aby uzyskać informacje o interakcji (trzymany przedmiot, podpowiedzi). HUD jest automatycznie ukrywany, gdy widok lobby jest otwarty.

◆ CreateCanvas()

void KitchenHUD.CreateCanvas ( )
inlineprivate

Tworzy programowo cały interfejs HUD, w tym Canvas, górny pasek statusu, pasek ulepszeń, panel podpowiedzi, powiadomienie toast, celownik, pływający tekst pieniędzy, panel timera zamówienia oraz tekst combo.

Metoda jest wywoływana raz w Awake. Sprawdza czy Canvas już istnieje, aby zapobiec duplikacji. Używa wbudowanej czcionki LegacyRuntime.ttf (lub Arial.ttf jako awaryjnej). Wszystkie elementy UI tworzone są ręcznie za pomocą metod pomocniczych CreatePanel, CreateText i CreateRoundedPill.

Odświeża wszystkie teksty i elementy HUD, w tym saldo, trzymany przedmiot, statystyki sesji, podpowiedzi, celownik, ulepszenia oraz efekty wizualne.

Aktualizuje wygląd celownika w zależności od tego czy gracz celuje w interaktywny obiekt oraz czy sklep jest otwarty.

Parametry

◆ UpdateToastAnimation()

void KitchenHUD.UpdateToastAnimation ( )
inlineprivate

Animuje pojawianie i zanikanie powiadomienia toast. Obsługuje interpolację przezroczystości, pozycji i skali panelu.

Animacja jest sterowana timerem toastTimer. Gdy timer spadnie do zera, panel płynnie zanika. Po całkowitym zaniku panel jest dezaktywowany. Używa Mathf.SmoothStep do uzyskania płynnej krzywej animacji.

◆ UpdateUpgradeStatus()

void KitchenHUD.UpdateUpgradeStatus ( )
inlineprivate

Aktualizuje pasek statusu ulepszeń, wyświetlając aktywne bonusy zakupione w sklepie (szybkość grilla, szybkość krojenia, bonus nagrody, dodatkowy czas, wielkość porcji mięsa).

Pasek jest ukrywany gdy nie zakupiono żadnych ulepszeń. Poszczególne bonusy są oddzielone separatorem "|". Wartości procentowe obliczane są na podstawie mnożników z ShopManager.

◆ UpdateUrgencyTimer()

void KitchenHUD.UpdateUrgencyTimer ( )
inlineprivate

Aktualizuje timer pilności aktualnego zamówienia. Wyświetla pozostały czas i zmienia kolor w zależności od pilności: zielony (>20s), złoty (10-20s), migający czerwony (<10s).

Gdy nie ma aktywnego zamówienia, timer jest ukrywany. Przy krytycznie niskim czasie (<10s) tło panelu również zmienia kolor na czerwonawy z efektem pulsowania.
