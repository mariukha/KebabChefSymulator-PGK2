Metody prywatne

void Start ()
 Inicjalizuje czcionkę, tworzy interfejs użytkownika i wyświetla menu.
 
void Update ()
 Aktualizuje animację przejścia menu w każdej klatce. Kontroluje przezroczystość, interaktywność oraz stan kursora i czasu gry. Gdy menu jest widoczne, czas gry jest zatrzymany, a kursor odblokowany.
 
void OnSoloClicked ()
 Obsługuje kliknięcie przycisku "Gra Solo". Ustawia tryb solo, konfiguruje slot zapisu, ukrywa menu i lobby, a następnie uruchamia hosta sieciowego na adresie lokalnym.
 
void OnMultiplayerClicked ()
 Obsługuje kliknięcie przycisku "Multiplayer". Ustawia tryb multiplayer, konfiguruje slot zapisu, ukrywa menu główne i wyświetla interfejs lobby do wyboru serwera.
 
void OnQuitClicked ()
 Obsługuje kliknięcie przycisku "Wyjdź". W edytorze Unity zatrzymuje tryb odtwarzania, w buildzie zamyka aplikację.
 
void OnSettingsClicked ()
 Obsługuje kliknięcie przycisku "Ustawienia". Otwiera panel ustawień gry za pomocą SettingsMenuUI.
 
void CreateUI ()
 Tworzy programowo cały interfejs użytkownika menu głównego. Buduje Canvas, tło, panel centralny, tytuł, separator oraz przyciski z odpowiednimi kolorami i zdarzeniami kliknięcia.
