Metody publiczne

void PlayChopSound ()
 Odtwarza efekt dźwiękowy krojenia noża. Używany przy krojeniu składników na desce do krojenia.
 
void PlayPickupSound ()
 Odtwarza efekt dźwiękowy podnoszenia przedmiotu. Używany gdy gracz podnosi składnik lub przedmiot ze stanowiska.
 
void PlayDropSound ()
 Odtwarza efekt dźwiękowy upuszczenia przedmiotu. Używany gdy gracz odkłada składnik na stanowisko.
 
void PlayMoneySound ()
 Odtwarza efekt dźwiękowy otrzymania pieniędzy. Używany przy pomyślnym zrealizowaniu zamówienia klienta.
 
void PlayFailSound ()
 Odtwarza efekt dźwiękowy niepowodzenia. Używany gdy zamówienie wygaśnie lub zostanie źle zrealizowane.
 
void PlayNewOrderSound ()
 Odtwarza efekt dźwiękowy nowego zamówienia. Używany gdy pojawia się nowe zamówienie od klienta.
 
void PlayButtonClick ()
 Odtwarza efekt dźwiękowy kliknięcia przycisku interfejsu. Używany we wszystkich interaktywnych elementach UI.
 
void PlayReadySound ()
 Odtwarza efekt dźwiękowy gotowości potrawy. Używany gdy składnik jest w pełni przetworzony i gotowy do użycia.
 
void PlayWrapSound ()
 Odtwarza efekt dźwiękowy zawijania kebaba. Używany gdy gracz zawija składniki w lawasz.
 
void PlayUpgradeSound ()
 Odtwarza efekt dźwiękowy zakupu ulepszenia. Używany gdy gracz kupuje ulepszenie w sklepie.
 
void StartGrillAmbient ()
 Rozpoczyna odtwarzanie zapętlonego dźwięku skwierczenia grilla. Dźwięk jest odtwarzany tylko jeśli nie jest już aktywny.
 
void StopGrillAmbient ()
 Zatrzymuje odtwarzanie zapętlonego dźwięku skwierczenia grilla.

Właściwości

static AudioManager Instance [get, private set]
 Statyczna instancja Singletona menedżera dźwięku. Umożliwia globalny dostęp do systemu audio z dowolnego miejsca w grze.
 
float MasterVolume [get]
 Aktualna wartość głównej głośności (tylko do odczytu). Zakres: 0.0 - 1.0.
 
float SFXVolume [get]
 Aktualna wartość głośności efektów dźwiękowych (tylko do odczytu). Zakres: 0.0 - 1.0.
 
float MusicVolume [get]
 Aktualna wartość głośności muzyki (tylko do odczytu). Zakres: 0.0 - 1.0.
 

Metody prywatne

void Awake ()
 Inicjalizuje Singleton menedżera dźwięku. Jeśli instancja już istnieje, niszczy duplikat obiektu.
 
void Start ()
 Konfiguruje źródła dźwięku, generuje wszystkie klipy audio proceduralnie, stosuje ustawienia audio z menedżera ustawień gry i rozpoczyna odtwarzanie muzyki.
 
void PlaySFX (AudioClip clip, float volumeScale)
 Odtwarza jednorazowy efekt dźwiękowy z domyślnym zakresem pitch (bez zmiany).
 
void PlaySFX (AudioClip clip, float volumeScale, float minPitch, float maxPitch)
 Odtwarza jednorazowy efekt dźwiękowy z losową zmianą wysokości tonu. Losowy pitch dodaje naturalne zróżnicowanie przy wielokrotnym odtwarzaniu tego samego efektu.
 
void PlayMusic ()
 Rozpoczyna odtwarzanie zapętlonej muzyki w tle. Głośność jest obliczana jako iloczyn głośności muzyki i głównej głośności.
 
void ApplyVolumes ()
 Aktualizuje głośność wszystkich aktualnie odtwarzanych źródeł dźwięku (muzyki i dźwięków otoczenia) na podstawie bieżących wartości głośności.
 
void GenerateAllClips ()
 Generuje proceduralnie wszystkie klipy audio używane w grze. Próbuje załadować muzykę z zasobów (Resources/Audio/music), a w przypadku braku pliku używa proceduralnie wygenerowanego dźwięku otoczenia.
 
AudioClip GenerateChop ()
 Generuje proceduralny klip dźwiękowy krojenia noża — ostry szum z szybkim wygaszeniem. Łączy biały szum z krótkim kliknięciem sinusoidalnym imitującym uderzenie ostrza.
 
AudioClip GeneratePickup ()
 Generuje proceduralny klip dźwiękowy podnoszenia — jasny, narastający ton. Częstotliwość rośnie od 400 Hz do 900 Hz, tworząc wrażenie podnoszenia.
 
AudioClip GenerateDrop ()
 Generuje proceduralny klip dźwiękowy upuszczenia — opadający ton. Częstotliwość spada od 700 Hz do 250 Hz, symulując efekt spadania.
 
AudioClip GenerateMoney ()
 Generuje proceduralny klip dźwiękowy pieniędzy — jasny podwójny dzwonek w stylu kasy fiskalnej. Składa się z kilku harmonicznych tonów z opóźnionym uderzeniem.
 
AudioClip GenerateFail ()
 Generuje proceduralny klip dźwiękowy niepowodzenia — opadający dysonansowy ton. Dwie bliskie częstotliwości tworzą efekt dudnienia, sygnalizujący błąd.
 
AudioClip GenerateNewOrder ()
 Generuje proceduralny klip dźwiękowy nowego zamówienia — jasny dzwonek z alikwotami i lekkim połyskiem, imitujący dzwonek w restauracji.
 
AudioClip GenerateClick ()
 Generuje proceduralny klip dźwiękowy kliknięcia przycisku — bardzo krótki, suchy dźwięk. Szybkie wygaszenie eksponencjalne tworzy wrażenie mechanicznego kliknięcia.
 
AudioClip GenerateReady ()
 Generuje proceduralny klip dźwiękowy gotowości — miękki metaliczny stuk z ciepłym tonem potwierdzenia. Łączy szum impulsowy z tonami harmonicznymi.
 
AudioClip GenerateWrap ()
 Generuje proceduralny klip dźwiękowy zawijania — szelest papieru/lawasza z kontrolowanym uderzeniem. Używa filtrowanego szumu i akcentów niskoczęstotliwościowych.
 
AudioClip GenerateUpgrade ()
 Generuje proceduralny klip dźwiękowy ulepszenia — kompaktowe arpeggio premium, nie głośna fanfara arcade'owa. Cztery nuty grane kolejno z lekkim połyskiem.
 
AudioClip GenerateGrillLoop ()
 Generuje proceduralny klip zapętlonego skwierczenia grilla — filtrowany szum z losowymi trzaskami i powolną modulacją amplitudy. Trwa 4 sekundy.
 
AudioClip GenerateMusicLoop ()
 Generuje proceduralny klip zapętlonej muzyki w tle — ciepły dron otoczenia z łagodną progresją akordów. Zawiera bas, akord trójdźwiękowy, pad szumowy oraz płynne wejścia i wyjścia (fade in/out). Trwa 16 sekund.
 
AudioClip CreateClip (string clipName, float[] data)
 Tworzy klip audio Unity z podanej tablicy próbek.
 
void OnDestroy ()
 Czyści referencję Singletona przy niszczeniu obiektu, zapobiegając odwoływaniu się do zniszczonej instancji.
