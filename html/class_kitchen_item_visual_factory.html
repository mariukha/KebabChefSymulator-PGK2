Opis szczegółowy

Statyczna klasa fabryki tworząca wizualne reprezentacje 3D składników i dań kuchennych w grze Kebab Chef Symulator.

Klasa pełni rolę centralnej fabryki do tworzenia obiektów wizualnych dla systemu kuchni. Obsługuje:

  • Ładowanie modeli 3D z katalogu Resources/Models/ z buforowaniem,
  • Tworzenie prymitywów zastępczych (kula, cylinder) gdy model nie jest dostępny,
  • Generowanie rozproszonych wizualizacji składników (posiekane warzywa, sos),
  • Buforowanie materiałów i shaderów dla optymalizacji wydajności,
  • Automatyczne skalowanie modeli do pożądanego rozmiaru,
  • Integrację z systemem animacji pojawiania się (ItemAnimator).

Tworzy zastępczą wizualizację składnika używając prymitywów geometrycznych (kula lub cylinder), gdy model 3D nie jest dostępny w zasobach.

Parametry
kindRodzaj składnika.
stateStan przetworzenia składnika.
isDishCzy obiekt jest gotowym daniem (kebabem) — jeśli tak, używany jest cylinder.
parentTransformata rodzica.
localPositionLokalna pozycja obiektu względem rodzica.
targetSizeDocelowy rozmiar obiektu.
Zwraca
Utworzony obiekt zastępczy z odpowiednim materiałem i kolorem.

Dania i kebaby reprezentowane są jako cylindry (0.4 × 0.7 × 0.4 targetSize), pozostałe składniki jako kule. Kolider jest wyłączany. Kolor jest automatycznie dobierany na podstawie rodzaju składnika za pomocą GetIngredientColor.

Tworzy wizualną reprezentację 3D składnika lub dania jako obiekt potomny podanego rodzica.

Parametry
kindRodzaj składnika do zwizualizowania.
stateStan przetworzenia składnika.
isDishCzy obiekt jest gotowym daniem.
parentTransformata rodzica, do którego zostanie dołączony model.
localPositionLokalna pozycja modelu względem rodzica.
localRotationLokalna rotacja modelu w stopniach (Euler).

Model jest skalowany za pomocą ScaleToSize do podanego rozmiaru. Wszystkie kollidery w modelu i jego dzieciach są wyłączane. Jeśli dostępny jest ItemAnimator, uruchamiana jest animacja pojawiania.

Tworzy wizualizację rozproszonych kawałków składnika (np. posiekane warzywa lub krople sosu), losowo rozmieszczonych w obrębie kontenera.

◆ ScaleToSize()

static void KitchenItemVisualFactory.ScaleToSize ( Transform modelRoot,
float targetSize )
inlinestaticprivate

Skaluje model 3D tak, aby jego największy wymiar odpowiadał podanemu rozmiarowi docelowemu.

Parametry
modelRootTransformata korzenia modelu do przeskalowania.
targetSizeDocelowy rozmiar największego wymiaru modelu.

Oblicza otoczkę (bounding box) ze wszystkich rendererów w modelu i jego dzieciach, wyznacza największy wymiar, a następnie skaluje cały model jednorodnie. Pomija modele o wymiarze mniejszym niż 0.001, aby uniknąć dzielenia przez zero.
