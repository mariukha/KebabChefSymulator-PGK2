Opis szczegółowy

Klasa singleton odpowiedzialna za konfigurację sieci w grze wieloosobowej.

Zarządza cyklem życia NetworkManager:

  • Tworzenie i konfiguracja NetworkManager oraz UnityTransport
  • Dynamiczne tworzenie prefabu gracza z wymaganymi komponentami
  • Uruchamianie trybu hosta lub klienta
  • Obsługa zdarzeń połączenia i rozłączenia graczy
  • Spawnowanie obiektów graczy na serwerze

Używa wzorca singleton z Instance.

void NetworkSetup.RegisterPrefabHandler ( )
inline

Rejestruje niestandardowy handler prefabu gracza w systemie prefabów Netcode.

Najpierw próbuje usunąć istniejący handler (ignorując błędy), a następnie dodaje nowy PlayerPrefabHandler. Powinno być wywoływane przed uruchomieniem hosta lub klienta.

◆ SetGlobalObjectIdHash()

static void NetworkSetup.SetGlobalObjectIdHash ( NetworkObject networkObject,
uint hash )
inlinestatic

Ustawia hash identyfikacyjny (GlobalObjectIdHash) obiektu sieciowego za pomocą refleksji.

Parametry
networkObjectObiekt sieciowy, którego hash ma zostać ustawiony.
hashWartość hasha do ustawienia.

Próbuje ustawić hash przez:

  1. Znane nazwy pól ("GlobalObjectIdHash", "m_GlobalObjectIdHash", "m_PrefabHash")
  2. Znane nazwy właściwości ("GlobalObjectIdHash", "PrefabHash")
  3. Brute-force — wyszukiwanie pól typu uint zawierających "hash" w nazwie

Jest to obejście braku publicznego API do ustawiania hasha w różnych wersjach Netcode.

inline

Uruchamia tryb hosta (serwer + klient) na podanym adresie.

Parametry
addressAdres nasłuchiwania serwera. Domyślnie "0.0.0.0" (wszystkie interfejsy).
