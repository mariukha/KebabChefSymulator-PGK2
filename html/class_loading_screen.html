Diagram dziedziczenia dla LoadingScreen

Metody prywatne

void Start ()
 Tworzy nakładkę ekranu ładowania i inicjalizuje licznik zanikania.
 
void Update ()
 Aktualizuje animację zanikania w każdej klatce. Zmniejsza przezroczystość nakładki proporcjonalnie do upływającego czasu. Po zakończeniu zanikania dezaktywuje obiekt nakładki.
 
void CreateOverlay ()
 Tworzy pełnoekranową nakładkę z tekstem wskazówki. Szuka istniejącego Canvas w trybie Screen Space Overlay lub tworzy nowy. Nakładka ma ciemny kolor tła i wyświetla losowo wybraną wskazówkę na dole ekranu.
 

Atrybuty prywatne

Image fadeOverlay
 Komponent Image służący jako nakładka zanikania (fade overlay). Pokrywa cały ekran ciemnym kolorem, który stopniowo staje się przezroczysty.
 
Text loadingText
 Komponent Text wyświetlający losową wskazówkę dla gracza podczas ładowania.
 
float fadeTimer
 Licznik czasu pozostałego do zakończenia animacji zanikania (w sekundach).
 
float fadeDuration = 1.8f
 Całkowity czas trwania animacji zanikania (w sekundach).
 
bool isFading = true
 Flaga określająca, czy animacja zanikania jest aktualnie w trakcie. Po zakończeniu zanikania ustawiana na false, a nakładka jest dezaktywowana.
 

Statyczne atrybuty prywatne

static readonly string[] Tips
 Tablica losowych wskazówek wyświetlanych na ekranie ładowania. Przy każdym uruchomieniu gry losowo wybierana jest jedna wskazówka.

◆ Update()

void LoadingScreen.Update ( )
inlineprivate

Aktualizuje animację zanikania w każdej klatce. Zmniejsza przezroczystość nakładki proporcjonalnie do upływającego czasu. Po zakończeniu zanikania dezaktywuje obiekt nakładki.

Używa Time.unscaledDeltaTime zamiast Time.deltaTime, aby animacja działała poprawnie nawet gdy gra jest wstrzymana (Time.timeScale = 0).
