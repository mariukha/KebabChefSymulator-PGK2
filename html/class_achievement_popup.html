Dokumentacja klasy AchievementPopup
Diagram dziedziczenia dla AchievementPopup

Właściwości

static AchievementPopup Instance [get, private set]
 Statyczna instancja Singletona systemu osiągnięć. Umożliwia globalny dostęp do wyświetlania powiadomień o osiągnięciach.
 

Metody prywatne

void Awake ()
 Inicjalizuje Singleton systemu osiągnięć i ładuje czcionkę. Jeśli instancja już istnieje, niszczy duplikat obiektu.
 
void Start ()
 Tworzy Canvas do wyświetlania powiadomień o osiągnięciach.
 
void Update ()
 Sprawdza kamienie milowe i aktualizuje stan wyświetlanych powiadomień w każdej klatce.
 
void CheckMilestones ()
 Sprawdza postęp gracza i próbuje odblokować odpowiednie osiągnięcia. Monitoruje liczbę zrealizowanych zamówień, serie sukcesów, zakupione ulepszenia oraz czy wszystkie ulepszenia osiągnęły maksymalny poziom.
 
void TryUnlock (string id, string title, string description)
 Próbuje odblokować osiągnięcie o podanym identyfikatorze. Jeśli osiągnięcie nie było jeszcze odblokowane, dodaje je do kolejki powiadomień.
 
void UpdatePopup ()
 Aktualizuje stan aktywnego powiadomienia — animuje wsuwanie, wygaszanie i usuwa powiadomienie po upływie czasu. Jeśli nie ma aktywnego powiadomienia, pobiera następne z kolejki oczekujących.
 
void ShowPopup (string title, string description)
 Tworzy i wyświetla wizualne powiadomienie o osiągnięciu na ekranie. Powiadomienie składa się z tła, złotego akcentu, tytułu i opisu. Wsuwa się z prawej strony ekranu i odtwarza dźwięk dzwonka.
 
void CreateCanvas ()
 Tworzy dedykowany Canvas do wyświetlania powiadomień o osiągnięciach. Canvas jest ustawiony w trybie Screen Space Overlay z wysokim porządkiem sortowania (160), aby powiadomienia były widoczne ponad większością elementów UI.
 
void OnDestroy ()
 Czyści referencję Singletona przy niszczeniu obiektu, zapobiegając odwoływaniu się do zniszczonej instancji.
 

Atrybuty prywatne

Canvas achievementCanvas
 Canvas używany do renderowania powiadomień o osiągnięciach. Wyświetlany jest w trybie Screen Space Overlay z wysokim porządkiem sortowania.
 
Font cachedFont
 Buforowana czcionka używana do renderowania tekstu w powiadomieniach. Ładowana jest z wbudowanych zasobów Unity.
 
readonly HashSet< string > unlocked = new HashSet<string>()
 Zbiór identyfikatorów już odblokowanych osiągnięć. Zapobiega wielokrotnemu odblokowania tego samego osiągnięcia.
 
readonly Queue< string[]> pendingPopups = new Queue<string[]>()
 Kolejka oczekujących powiadomień do wyświetlenia. Każdy element to tablica dwuelementowa: [tytuł, opis].
 
GameObject activePopup
 Aktualnie wyświetlany obiekt powiadomienia (popup). Wartość null oznacza brak aktywnego powiadomienia.
 
float popupTimer
 Licznik czasu pozostałego do zamknięcia aktywnego powiadomienia (w sekundach).
 
int lastCompleted
 Ostatnia zapamiętana liczba zrealizowanych zamówień. Służy do wykrywania nowych ukończonych zamówień w kolejnych klatkach.
 
int lastFailed
 Ostatnia zapamiętana liczba nieudanych zamówień. Służy do wykrywania nowych porażek i resetowania serii sukcesów.
 
int consecutiveSuccess
 Licznik kolejnych sukcesów bez porażki. Resetowany przy każdym nieudanym zamówieniu.
 
int lastUpgradeCount
 Ostatnia zapamiętana łączna liczba zakupionych ulepszeń. Służy do wykrywania nowych zakupów ulepszeń.
 

Statyczne atrybuty prywatne

const float PopupDuration = 3.5f
 Czas wyświetlania pojedynczego powiadomienia o osiągnięciu (w sekundach).
 
const float SlideSpeed = 6f
 Szybkość animacji wsuwania powiadomienia na ekran. Wyższa wartość oznacza szybsze wsunięcie.
