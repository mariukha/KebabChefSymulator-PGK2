Opis szczegółowy

Klasa ScriptableObject reprezentująca dane pojedynczego składnika w grze. Przechowuje informacje o nazwie, cenie, ikonie, modelu 3D oraz parametrach gameplayowych składnika, takich jak typ, stan początkowy i wartość sprzedaży.

Nowe instancje można tworzyć z poziomu menu Unity: Assets → Create → KebabGame → Skladnik. Każdy składnik posiada zarówno dane prezentacyjne (ikona, model 3D), jak i dane logiki gry (typ, stan, wartość).
